# Продвинутое машинное обучение

Магистерская программа «Науки о данных», НИУ ВШЭ. Учебный год 2026.

Здесь лежат материалы курса: слайды лекций, семинарские ноутбуки, практики на бонусные баллы, литература и программа дисциплины. Домашние задания выдаются и сдаются в Google Классе.

## Сдача домашних заданий

### [→ Вступить в курс в Google Классе](https://classroom.google.com/c/ODczMzIwMTE0MTI2?cjc=6btott77)

Ссылка одна на весь поток. Если она не открывается — зайти на [classroom.google.com](https://classroom.google.com), нажать **+** → «Присоединиться» и ввести код курса: **`6btott77`**

Решение сдаётся файлом `.ipynb` **с сохранённым выводом ячеек**: проверяющий не перезапускает код. Перед сдачей — `Kernel → Restart & Run All`, чтобы убедиться, что ноутбук считается сверху вниз без ошибок. Код — половина работы, вторая половина — выводы.

Оценки и комментарии проверяющий оставляет там же, в Классе.
