# Продвинутое машинное обучение

Магистерская программа «Науки о данных», НИУ ВШЭ. Учебный год 2026.

Здесь лежат все материалы курса. Домашние задания выдаются отдельно, через GitHub Classroom.

## Что где лежит

```
advanced-ml/
├── syllabus/      программа учебной дисциплины (ПУД)
├── lectures/      слайды лекций
├── seminars/      ноутбуки семинаров
├── practice/      задания к лекциям на бонусные баллы
├── references/    список литературы со ссылками
└── env/           окружение: requirements.txt
```

**`lectures/`** — папка на лекцию, номер совпадает с номером занятия: `lectures/01/`, `lectures/02/`. Внутри `slides.pdf` и, если есть, дополнительные разборы отдельными файлами.

**`seminars/`** — папка на семинар, названа номером и темой: `seminars/01-02-trees-ensembles/`. Сдвоенные семинары идут одной папкой с диапазоном в номере. Внутри `seminar.ipynb`.

**`practice/`** — необязательные задания на бонусные баллы. Нумерация по номеру лекции, к которой задание относится: `practice/01/practice.ipynb`. Подробности — в [practice/README.md](practice/README.md).

**`references/`** — учебники не хранятся в репозитории (PDF на десятки мегабайт навсегда осели бы в истории git и замедлили клонирование). Вместо них [ссылки](references/README.md) на официальные страницы, где авторы выкладывают книги бесплатно.

**Домашние задания** лежат не здесь. Каждое ДЗ — отдельный репозиторий, который GitHub Classroom создаёт персонально для студента по ссылке-приглашению.
